# FlixFindr 

A modern movie discovery web application built with Vanilla JavaScript and powered by the TMDB API.

Browse trending titles, explore genres, discover curated collections, manage your personal watchlist, and view detailed movie information — all through a fast and responsive interface.

---

## Tech Stack

Frontend
- HTML5
- CSS3
- JavaScript

Backend 
- Vercel Serverless Functions

API
- TMDB API

Deployment
- Vercel

---

## Features

- Browse Trending Movies
- Popular, Top Rated and New Releases
- Genre-based Discovery
- Curated Movie Collections
- Movie Detail Modal
- Official Trailer Support
- Personal Watchlist
- Responsive Design
- Skeleton Loading Animations
- Toast Notifications
- TMDB Powered Search
- Secure Backend Proxy using Vercel Functions

 ## Getting Started

 Clone the repository
- git clone https://github.com/princepathak25/flixfindr.git

 Install dependencies
- npm install

 Run locally
- vercel dev

---

## Environment Variables

Create a `.env` file inside the project root.

TMDB_API_KEY=YOUR_API_KEY
